# 🍽️ Gourmet Delight

A responsive recipe website built entirely with **HTML and CSS**. It features **60 recipe pages** with ingredient lists and step-by-step instructions, across **70 files** in total.

## ✨ Features

- 60 recipe cards, each linking to its own recipe page
- Recipe categories: Classic Community Dishes, International Dishes, Breakfast Dishes and more
- Recipes dropdown menu and search bar in the navigation
- About Us page (website overview and services)
- Contact Us page (message form, contact details, FAQ)
- Newsletter sign-up and social links in the footer
- Fully responsive layout for desktop, tablet and mobile

## 🛠️ Tech Stack

- **HTML5**: page structure
- **CSS3**: styling and responsive layout

No JavaScript or frameworks are used.

## 🚀 Getting Started

1. Clone or download the repository:
   ```bash
   git clone (https://github.com/SanaShahzad1116/Gourmet-Delight.git)
   ```
2. Open the `Gourmet Delight` folder.
3. Open `index.html` in any web browser.
